# Password Strength Analyzer 🔐

## Project Overview
Password Strength Analyzer is a Python-based cybersecurity project that evaluates password strength using different security criteria.

It classifies passwords into three categories: Weak, Medium and Strong.

## Objectives
- Understand basic password security.
- Evaluate password strength using Python.
- Identify weak password patterns.
- Provide suggestions for creating stronger passwords.

## Features
1. Password length verification.
2. Uppercase letter detection.
3. Lowercase letter detection.
4. Number detection.
5. Special character detection.
6. Common password detection.
7. Password strength classification.
8. Suggestions for improvement.

## Technologies Used
- Python
- Regular Expressions
- Getpass Module
- Visual Studio Code
- GitHub
